이번 시간에는 BindingResult에 대해 자세히 배워보겠다. 
・BindingResult가 있는 경우
-> 타입 오류 등이 있어도 컨트롤러가 실행이 된다. 그리고 자동으로 FieldError 객체를 만들어서 BindingResult 객체에 반환을 한다.

・BindingResult가 없는 경우
-> 타입 오류 등이 있으면 애초에 컨트롤러가 실행이 안되며, 웹 서버가 HTTP 에러 페이지를 발생한다.

BindingResult로 검증을 하는 3가지 방법
1. 개발자가 직접 넣어 준다.
2. BindingResult의 자동 기능 이용
3. validator 사용(추후에 학습)
